## About

A-T-Field-Status is an open-source tool that generates customizable SVG progress widgets based on a hexagonal grid.

It was originally created for the **EVA-60** mechanical keyboard project, but is designed to work with any project.

The goal is to provide a visually appealing alternative to traditional progress bars while remaining lightweight, customizable and fully generated from code.

---

## Features

- SVG generation
- Hexagonal progress grid
- Lightweight
- Highly customizable
- GitHub README friendly
- Open source
